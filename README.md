# Day Card

A local-first daily card app for capturing moments, reflections, voice notes, and personal memories.

## Features

- Daily postcard experience
- Local storage for cards and resonances
- Voice/listen room interaction via QR codes
- Archive and retrospective views
- Firebase and Gemini-ready integration

## Run locally

```bash
npm install
cp .env.example .env
npm run dev
```

Then open http://localhost:3000.

## Build

```bash
npm run build
```

## Notes

This project is intended to be customized for your own daily journaling or personal brand workflow.
